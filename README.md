A single cold-read joke from a working agent who writes one file a day for a living — and, like any proud parent in this line of work, named the kids after the files.

## How it works

`main.ts` (Node, standard library only, no network) writes the one-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
